## 3. Long description (store page)

### Design and code that finally match

Most UI kits stop at Figma, or ship code that only looks a bit like the design. Facet UI is built as one system in three layers that stay in sync: a **Figma library**, **design tokens**, and **code** in both plain HTML/CSS/JS and **animated React components**. Every color, space, radius, shadow and text style is a token with the same name in Figma, CSS, JSON and Tailwind, so handoff is a lookup, not a guess.

### Re-brand everything in one click

Pick one of six built-in brands (Iris, Ember, Lagoon, Rose, Cobalt, Forest) or paste **any hex color**. Facet generates a full 11-step brand ramp in OKLCH and checks contrast automatically, so primary buttons and links stay WCAG AA whatever color you choose. Switch light and dark, comfortable and compact density, and four style themes (Default, Soft, Glass, Mono) the same way: one Variable mode in Figma, one attribute in code.

### Components with a point of view

Facet has its own visual language, not another copy of the same look. **The Facet cut** gives every container one sharper corner; **the signal rail** marks what's active with a 3 px brand bar. Micro-interactions run through everything: buttons lift and ripple, switches spring, tabs glide, charts grow from the baseline, KPIs count up. It all respects reduced motion and can be turned off with one setting.

### Built for modern products, including AI

Beyond the standard set (buttons, forms, tables, overlays, navigation), Facet includes the components modern products need now: KPI cards and charts, data grids, kanban, command palette with AI scope, chat conversations, prompt input, chain of thought, tool calls with approval, sources and citations, message scroller, streaming text, and six working AI agent demos to learn from.

### Install it, own it

React developers run `npx facetui@latest init`, then `npx facetui@latest add dialog tabs` or `add --all`. The components land in your own project, built on Radix primitives and Tailwind CSS v4 with motion on every interaction, so you can read and change every line.

### Ready-made pages and AI-ready docs

Start faster with 36 page blocks (heroes, pricing, dashboards, checkout and more), three complete app pages, and ten Figma app templates with 26 desktop and mobile screens. The download includes a single Markdown guide, `FACETUI-LLMS.md`, that teaches ChatGPT, Claude, Cursor or Copilot how to build with Facet correctly.

## 9. FAQ

**Do I need to know React?**
No. Use the Figma file on its own, or the plain HTML/CSS/JS version in any stack. The React components are there if you want them.

**Can I use my own brand color?**
Yes. Paste any hex color and Facet builds the full ramp with contrast checks, in Figma and in code.

**Does it work with Tailwind?**
Yes. The Tailwind preset maps the common semantic class names to Facet tokens, and the React components are built with Tailwind CSS v4.

**Is there dark mode?**
Yes, for every component, template and brand, plus compact density and four style themes.

**Can I use it in client and commercial projects?**
Personal covers personal and client projects; Commercial and Team add products you sell. You can't resell the kit itself.

**Do I get updates?**
Every release is listed in the public changelog at facet.etkits.us/#/changelog. *(Ben: add your update policy here, e.g. "free updates for 1.x".)*

**Does it work with AI coding tools?**
Yes. Give `FACETUI-LLMS.md` to ChatGPT, Claude, Cursor or Copilot and they'll use the right tokens, classes and components. Each component page also has Copy Markdown.

**What do I need for Figma?**
A Figma Professional plan (or higher) to switch variable modes, and the free Mona Sans font.
