questions

What is ETKits?

ETKits is a collection of UI kits by ELTouch apps. Each kit is a complete design system: a Figma library, design tokens and a coded component implementation that stay in sync.

What is in Facet UI?

144 Figma components with variants, 228 design variables, 10 app templates, 6 brand themes, 4 style themes, light and dark modes, and a dependency-free HTML/CSS/JS style guide with 6 working AI agent demos.

Which frameworks does it work with?

The coded components are plain HTML, CSS and JavaScript, so they drop into any stack. Tokens are also exported as a Tailwind preset and follow shadcn/ui's component model and naming.

Does it support dark mode?

Yes. Every component has light and dark values through semantic color tokens, in Figma and in code.

Where can I buy it, and how do I get the Figma file?

Facet UI is sold on Gumroad, Envato Market and UI8. Gumroad and Envato buyers enter their license key or purchase code on the claim page to unlock the Figma file and the code and tokens download. UI8 buyers download everything from UI8. The license from your store covers your use.

Are more kits coming?

Yes. Facet UI is the first release, and new kits will be added here as they ship.
