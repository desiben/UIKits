What's included

Three layers in every kit.

Design and code stay in step, so what you see in Figma is what ships.

Figma library

Components built on Variables, variants and Auto Layout, with light/dark modes, brand themes and ready-made app templates.

Design tokens

Exported as CSS custom properties, W3C DTCG JSON and a Tailwind preset, so the code matches the file.

Coded components

Dependency-free HTML/CSS/JS with live previews and copy-paste snippets, ready to drop into any stack.

Roadmap

Facet UI is the first. More kits are on the way.

Each new ET-UIKit follows the same standard: a complete Figma library, tokens and coded components, documented and ready to use.
