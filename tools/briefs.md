# Template briefs

Each template's identity. Prefix = CSS class prefix. Stretch = `--k-stretch-display` / `--k-stretch-heading`. Brands marked "custom" use `theme.custom.hex` with `theme.brand` set to the template slug. Done: healthcare (hl), architecture (sv), gaming (nf).

## technology · Relaypoint · prefix rp
Workflow automation SaaS for operations teams (finance ops, people ops, IT) at 50–1,000 person companies. Light, iris, default style, comfortable. Stretch 96/98.
Hero archetype: **working product preview**. A mini app UI built from Facet components (not a screenshot): a workflow canvas showing trigger → condition → action steps; tabs above switch between three real workflows (invoice approval, new-hire onboarding, access requests) and the canvas updates. Signature: that live canvas.
Sections: integrations as a text-wordmark grid of fictional tools, use cases by team (tabs), a plain-language security section (no certification claims; "security review pack for your IT team"), a usage-based cost estimator instead of a pricing grid (runs/month segment → illustrative monthly cost).
Inner: one feature page per workflow (3). Conversion: demo request (single page: work email, company size select, team choices, tools-you-use chips as checkboxes, preferred time window).
