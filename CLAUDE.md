# Branch rules

- This branch (`FacetUI`) holds all Facet UI content. Every Facet UI change is committed and pushed here, never to `main`.
- `main` is reserved for the ETKits marketing landing page, which shows Facet UI as a showreel thumbnail (`kits/facetui/` on `main`).
- Never link the Figma source file or the (private) repo from public pages: the ETKits site, the style guide and its marketing page. The Figma file is delivered to buyers only after purchase.
