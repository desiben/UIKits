One-liner

A token-driven Figma UI kit with 88 components, 10 app templates, light/dark and 6 brand themes, plus live code.

Short description

Facet UI is a professional Figma UI kit for SaaS, dashboards and AI products. Every component is built with Auto Layout and bound to Variables, so you can switch brand, light/dark and density in one click. It ships with 88 components, 420+ variants, 10 app templates with 26 desktop and mobile screens, and a matching HTML/CSS style guide with tokens, a Tailwind preset and shadcn/ui naming.

Feature bullets
  • Built for Figma — no plugins or setup required
  • Fully editable colors, grids, spacing, radius and type styles
  • Auto Layout + Variables for instant theme switching
  • Organized layers, semantic naming and a systemized structure
  • Pixel-perfect, professional and scalable components
  • Works equally well for light, dark and custom brand themes
  • Micro-interactions and a live code style guide included
