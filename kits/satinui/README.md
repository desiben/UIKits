# Satin UI Kit

Satin is the design system; Sanoa is its workspace template collection.

## Development

`npm ci`, `npm run build`, then `npm run dev`. Run `npm test` for catalog, icon and JSX validation.

## Deployment

Private repository `desiben/UIKits`, branch `main`, project root `kits/satinui`. Vercel builds with `npm run build` and serves only `dist`. Domain: `satin.etkits.us`.

The public build does not ship the editable source archive or master Figma URL. Buyer delivery remains with the ETKits license hub; Satin product registration and checkout delivery must be configured separately before selling.

## Coverage

109 component families, 61 blocks, 10 templates, 6 agent examples and 14 motion demonstrations. Brand, style and color-mode choices persist locally. Demo account, payment and AI flows do not contact production backends.

Barlow and Lucide licenses are in `public/assets`. Source media credits are in `ASSET-CREDITS.json`. Exact Figma parity and an independent accessibility review are not certified.
